尚未選擇地區
先選一個地區，就會列出 eBird 在那裡歷年紀錄過的所有鳥種（含過境鳥和迷鳥），看過的打勾就好。
鳥況資料來自 eBird（Cornell Lab of Ornithology），使用每位使用者自己的 API 金鑰。鳥類照片來自 iNaturalist 觀察者，版權依各張署名。地圖 © Esri / OpenStreetMap。僅供個人、非商業用途。

eBird API 金鑰

到 ebird.org/api/keygen 登入後就能免費拿到一組金鑰，貼在下面。它只會存在你自己這台電腦的瀏覽器裡。

我的 eBird 紀錄（選填）

到 ebird.org/downloadMyData 申請下載，eBird 會寄一個 zip 給你，解壓縮後把 MyEBirdData.csv 選進來，就能標出「新種」。也可以選之前備份的 lifelist.txt 還原。

自動同步到 GitHub（網站主人用）

貼上只能修改這個 repository 的 GitHub 權杖後，你打勾的鳥種會自動存進 lifelist.txt（只有學名，沒有地點日期），手機、電腦和每日推播都會用同一份。建立權杖。不要在別人的電腦上貼。

選擇鳥種清單的地區

清單是 eBird 在這個地區歷年所有紀錄過的鳥種，包含過境鳥和迷鳥。地區越小，清單越短。
